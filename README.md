# Grok Bot Starter Pack

**Free DIY templates** for one-job Grok Bot / Cursor agents. Clone, paste, run.

**Not for sale** — no paid install, no DFY SKUs, no checkout in this repo.

## Install

1. Pick a persona in `personas/` **or** the full [speed-to-lead/](speed-to-lead/) kit.
2. Create a Grok Bot / Cursor agent → paste **SYSTEM** / description from the file.
3. Add skills from `speed-to-lead/skills/` (for the STL desk).
4. Connect one connector (usually Gmail).
5. Run [speed-to-lead/FIRST-WAKE.md](speed-to-lead/FIRST-WAKE.md) once — **drafts only, never auto-send**.

| Persona | Job | Mode |

| [Found-Money Scanner](personas/found-money-scanner-draft-only.md) | Refunds / unused subs / credits | Draft only |

## Safety defaults

- **Never send** mail/social unless the human says “send it”.
- Cap burn: one connector, narrow query, stop when the brief is done.
- No new KYC / Stripe / Whop from these bots.
