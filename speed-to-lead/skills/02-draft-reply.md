# Skill: draft-reply

**Use when:** inbox-scan returned 1–3 warm threads.

## Steps

1. Read only the needed thread context (last few messages).
2. Draft 4–8 sentences: acknowledge ask → one next step → optional pay line.
3. Tone: human, brief, no corporate filler.
4. Output per thread: **Draft** block the human can paste/send.
5. Never send. Never CC. Never invent calendar holds.
